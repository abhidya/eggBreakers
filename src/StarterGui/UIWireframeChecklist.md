# UI Implementation Checklist
- HatchScreen: crack meter, input prompt, muffled overlay, no first-hatch skip, four curated starter options (Coelophysis, Parasaurolophus, Utahraptor, Citipati) plus a fifth full-roster random species option, selected-state continuity through hatch.
- MainHUD: health, hunger, thirst, stamina, growth, diet, species, movement badge, rest/sleep, age, dying/death state, notifications.
- MobileControls: thumbstick, eat/drink, attack, sprint, call, rest/hide.
- SpeciesInfoPanel: name, diet, role, movement, stage, abilities, unlock.
- GroupPanel: invite, leave, member list, Herd/Pack.
- DeathScreen: cause, life progress lost, account rewards kept, egg/nest respawn.
- CityDiscoveryPopup: Old Eden discovered, lore line, fossil hint.
