# UI Implementation Checklist
- HatchScreen: crack meter, input prompt, muffled overlay, no first-hatch skip.
- MainHUD: health, hunger, thirst, stamina, growth, diet, species, notifications.
- MobileControls: thumbstick, eat/drink, attack, sprint, call, rest/hide.
- SpeciesInfoPanel: name, diet, role, stage, abilities, unlock.
- GroupPanel: invite, leave, member list, Herd/Pack.
- DeathScreen: cause, life progress lost, account rewards kept, egg/nest respawn.
- CityDiscoveryPopup: Old Eden discovered, lore line, fossil hint.
