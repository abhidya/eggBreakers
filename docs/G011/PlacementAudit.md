# G011 Placement Audit

- No square/grid placement: manifest entries use `PlacementPattern=natural_offset_no_grid`.
- Clear travel paths: manifest entries use `AvoidRouteCenters=true`; route terrain remains separately generated by `MapLayoutService.RouteTerrain`.
- Trees/bushes: classified to `NaturalGroveEdge` or `SwampBankEdge`, not path centers.
- City ruins/cars/rubble: classified to `ApocalypticCity`.
- Rocks/cliffs: classified to `RedstoneCanyon` or `MountainNestingCliffs`.
- Swamp assets: classified to `SwampDelta`.
- Fossils: classified outside safe zones, never `NurseryGrove`.
- Terrain underlay: `MapLayoutService.FullMapTerrainUnderlay` is one 4700 x 12 x 4400 terrain base under all biomes and routes.
